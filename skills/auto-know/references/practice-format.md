# 八股练习记录格式

面试出题模式读写练习记录时遵循本文件。

## 文件位置

```text
<knowledge-root>/practice/know-record.md
```

目录不存在则创建。该文件只服务出题冷却与作答回顾，不写入专题正文。

## 完整模板

```markdown
# 八股练习记录

> 用于出题去重与作答回顾；由面试出题模式自动追加。
> 最近更新：YYYY-MM-DD

## 出题索引

| 稳定 ID | 问题标题 | 专题文件 | 最近出题时间 | 作答次数 | 重点 |
|---------|----------|----------|--------------|----------|------|

## 练习明细

### YYYY-MM-DD HH:mm — {问题标题}

- 稳定 ID：`{stable-id}`
- 来源文件：`{relative-path}`
- 面试提问：{实际向用户说出的问法}
- 用户作答：{原文保留}
- 评分：{x/10} — {一句话总评}
- 口述要点（评分基准）：{可直接面试口述的完整答案；关键结论须带因果（步骤/已知未知/缺了会怎样），禁止空结论标签}
- 差距：{一段话：用户原意 → 为何不行 → 对照正确机制；禁止只写「说偏了/未提到 X」}
```

## 字段规则

- **稳定 ID**：与知识库条目 `<a id="...">` 一致，作为冷却与去重主键。
- **最近出题时间**：本地时区 `YYYY-MM-DD HH:mm`；出题当下更新索引，答完后写明细。
- **作答次数**：每完成一次评分 +1；仅出题未作答不增加次数，但仍更新最近出题时间（计入冷却）。
- **重点**：单元格为 `是` 表示用户在作答后将该题标为重点；空表示普通题。重点题使用更短冷却（见下）。
- **口述要点**：写成可直接面试口述的完整答案（约 45～90 秒）；每个关键结论讲清因果链（停在哪一步、各方已知/未知、少一步会怎样），禁止「要保证××」「因为确认不了」这类有结论无展开的句子；禁止电报式关键词罗列；禁止粘贴专题长文、大表、源码细枝与扩展追问。
- **评分**：统一 10 分制（如 `7/10`），另附一句总评。
- **差距**：一段话写清「用户怎么说 → 为何这样不够/错了 → 正确差在哪一步」；必须让读者明白原先答法为什么不行，禁止只标注「说偏了」「未提到 X」。
- **用户作答**：原样归档，可做最低限度空白整理，不润色观点。

## 选题与冷却

1. **粒度**：冷却与索引主键是**主问题**稳定 ID，不是递进追问下的每个小问。
2. 普通题冷却天数 `quizExcludeDays = 14`（用户级 `config.json` 可覆盖；本轮用户明示可临时覆盖）。
3. 重点题冷却天数 `quizFocusExcludeDays = 7`（用户级配置可覆盖）。索引「重点」列为 `是` 时使用该值，否则使用普通冷却。
4. 硬排除：对主问题取适用的 N 后，若「最近出题时间」落在最近 N 个自然日内则整组不得再出。
5. 优先顺序：从未出现在索引中 → 最近出题时间最早 → 同优先级下可随机。
6. 用户指定专题/文件时，只在该范围内选题。
7. 若冷却后无候选：放宽为「全局最久未出」，并在对话中说明已放宽冷却。
8. 用户作答评分后可声明「加重点 / 取消重点」；更新索引「重点」列后立即按新冷却规则生效。

## 可出题单元

**主单元（可选题、占冷却）**同时满足：

- 有稳定 ID（`<a id="...">`）
- 有可识别的问题标题（真实问法或可改写成面试问句）
- 有「简答」或等价直接答案区块，足以提炼口述要点
- 是栏目下的主问题（通常 `##` / `###`），**不是**「递进追问」下的 `####` 子问题

**捆绑子问（随主问题一并提问，不单独选题/冷却）**：

- 主问题「递进追问」内的 `####` 子问题
- 或紧随其后、明显延续同一主问题语境的延伸小问（由出题时判断纳入）

排除：纯栏目标题、纯来源块、`_sources/` / `_tools/` / `practice/` 下的文件、无法独立成题的碎片。
