# 八股练习记录格式

面试出题模式读写练习记录时遵循本文件。

## 文件位置

```text
<knowledge-root>/practice/know-record.md
```

目录不存在则创建。该文件只服务出题冷却与作答回顾，不写入专题正文。

## 完整模板

```markdown
# 八股练习记录

> 用于出题去重与作答回顾；由面试出题模式自动追加。
> 最近更新：YYYY-MM-DD

## 出题索引

| 稳定 ID | 问题标题 | 专题文件 | 最近出题时间 | 作答次数 |
|---------|----------|----------|--------------|----------|

## 练习明细

### YYYY-MM-DD HH:mm — {问题标题}

- 稳定 ID：`{stable-id}`
- 来源文件：`{relative-path}`
- 面试提问：{实际向用户说出的问法}
- 用户作答：{原文保留}
- 评分：{等级或分数} — {一句话总评}
- 口述要点（评分基准）：{压缩后的正确回答重点，非文档原文拷贝}
- 差距：{相对口述要点的缺漏与错误}
```

## 字段规则

- **稳定 ID**：与知识库条目 `<a id="...">` 一致，作为冷却与去重主键。
- **最近出题时间**：本地时区 `YYYY-MM-DD HH:mm`；出题当下更新索引，答完后写明细。
- **作答次数**：每完成一次评分 +1；仅出题未作答不增加次数，但仍更新最近出题时间（计入冷却）。
- **口述要点**：只保留能答对该题的核心结论与必要因果，适合约 30～90 秒口述；禁止粘贴专题中的长文、大表、源码细枝与扩展追问。
- **用户作答**：原样归档，可做最低限度空白整理，不润色观点。

## 选题与冷却

1. 默认冷却天数 `quizExcludeDays = 14`（用户级 `config.json` 可覆盖；本轮用户明示可临时覆盖）。
2. 硬排除：索引中「最近出题时间」落在最近 N 个自然日内的题目。
3. 优先顺序：从未出现在索引中 → 最近出题时间最早 → 同优先级下可随机。
4. 用户指定专题/文件时，只在该范围内选题。
5. 若冷却后无候选：放宽为「全局最久未出」，并在对话中说明已放宽冷却。

## 可出题单元

从知识库 Markdown 收集同时满足以下条件的条目：

- 有稳定 ID（`<a id="...">`）
- 有可识别的问题标题（真实问法或可改写成面试问句）
- 有「简答」或等价直接答案区块，足以提炼口述要点

排除：纯栏目标题、纯来源块、`_sources/` / `_tools/` / `practice/` 下的文件、无法独立成题的碎片。
