# 过往经历练习记录格式

过往经历提问模式读写练习记录时遵循本文件。字段语义与 [practice-format.md](practice-format.md) 对齐，文件独立，避免与八股练习混索引。

## 文件位置

```text
<knowledge-root>/practice/resume-record.md
```

目录不存在则创建。该文件只服务经历出题冷却与作答回顾，不写入简历或参考回答正文。

## 完整模板

```markdown
# 过往经历练习记录

> 用于经历出题去重与作答回顾；由过往经历提问模式自动追加。
> 最近更新：YYYY-MM-DD

## 出题索引

| 稳定 ID | 问题标题 | 来源 | 最近出题时间 | 作答次数 | 重点 |
|---------|----------|------|--------------|----------|------|

## 练习明细

### YYYY-MM-DD HH:mm — {问题标题}

- 稳定 ID：`{stable-id}`
- 来源：`{questions-section-or-resume-bullet}`
- 面试提问：{实际向用户说出的问法}
- 用户作答：{原文保留}
- 评分：{x/10} — {一句话总评}
- 口述要点（评分基准）：{可直接当面试口述的完整答案；约 45～90 秒口播，含结论、关键行动与结果，不啰嗦、非关键词罗列}
- 差距：{一段话说明相对口述要点的具体缺漏与错误；可略释机制，不分点、不堆黑话结论}
```

## 字段规则

- **稳定 ID**：问题集用 `resume-{章号}-{题号}`；简历衍生用 `resume-exp-{sha12}`。作为冷却与去重主键。
- **来源**：问题集写 `interview-questions.md#A2` 这类章节定位；简历衍生写 `resume.md` 对应要点摘要（一句话即可）。
- **最近出题时间 / 作答次数 / 重点**：同八股练习记录。
- **口述要点**：优先压缩自 Talk / QA-star / QA 相关段落，写成可直接面试口述的完整答案；禁止整篇粘贴材料原文。
- **评分 / 差距 / 用户作答**：同八股练习记录（10 分制；差距一段话）。

## 选题与冷却

1. **粒度**：冷却与索引主键是**主问题**稳定 ID；问题集中的「追问」随主问捆绑，不单独占行。
2. 普通题冷却：`resumeQuizExcludeDays`，未配置则用 `quizExcludeDays`（默认 14）。
3. 重点题冷却：`resumeQuizFocusExcludeDays`，未配置则用 `quizFocusExcludeDays`（默认 7）。
4. 硬排除、优先顺序、范围限定、冷却放宽、加重点：同八股 `practice-format.md`「选题与冷却」第 4～8 条，读写本文件。

## 可出题单元

**主单元（可选题、占冷却）**：

- 来自 `interview-questions.md` 的编号主问；或
- 从 `resume.md` 实习/项目/自我描述要点提炼出的独立面试问句

**捆绑子问**：

- 主问下的「追问：…」
- 面试官顺势深挖的同一项目细节（出题时判断纳入，不单独建索引行）

排除：纯岗标题/章标题、材料说明性引用块、无法独立成题的碎片、八股知识库条目。
