# 自学八股问答归档

## 触发与范围

- 日常问答按用户当次要求解释，允许详细展开；只有明确要求归档，或明确调用本 skill 执行八股归档时才写入。
- 安装、拉取、同步、修改技能，以及仅询问或分析技能能力时，不自动归档学习内容。
- 默认整理当前对话中尚未完整归档的八股知识；用户指定部分问题时以指定范围为准。排除业务决策、技能管理、操作指令和闲聊，不主动扩展为网上题库收集或面试练习。

## 目标文档

1. 优先使用本轮指定的文件，其次使用当前对话已明确约定的自学文件，再使用用户级配置中的 `selfStudyQaFile`。
2. 均未指定时，在当前项目的 `knowledge/`、配置默认目录的 `knowledge/` 中查找与知识领域匹配的 `*-八股-自己学习版.md` 或同用途自学文档；先读内容再判断归属，唯一强匹配才复用。
3. 多个候选同等匹配时询问用户；确无匹配时，在 Phase 2e 解析的知识目录中新建 `{领域}八股-自己学习版.md`，并说明创建原因。明确指定的文件不存在时提示用户，不静默改用其他文件。
4. 机器绝对路径只存于用户级配置；配置示例保留空值，不将本机路径写进技能源码。

## 问题与答案

- 同时扫描用户提问、图片中的题目、批注追问和 Agent 回答。无法读取图片或历史内容时说明缺口，不补造原问。
- 保留用户原问的对象、比较维度、因果关系和条件，仅去口头赘词、修正错字和补全指代。独立追问保留为可检索问题，不能只留下父主题；重复或强相关问题可合并，但必须覆盖全部疑问。
- 从回答中补收具有独立价值的必要原理、误区与边界，不机械地把每句话变成新题，不添加对话之外的题目。
- 答案先直接给出结论，再保留回答该问题必需的原因、条件和易错点。删除重复解释、教学铺垫和冗长示例，不设固定字数，不因追求短小而遗漏要点。
- 默认使用短段落或少量分点；比较题可用表格，仅在必要时保留简短代码。文档要便于快速查阅，不照搬长篇对话，也不统一套用“定义/原理/示例/注意事项”模板。
- 例如 `String` 的线程安全问题，必须区分不可变对象的安全共享与共享引用更新的原子性；`StringBuffer` 的单方法线程安全不能表述为多次调用整体原子。示例用于约束表达，不据此自动新增题目。

## 去重、预览与写入

1. 全文读取目标文档，对照问题和答案语义判断已有覆盖；父主题出现不代表追问已归档。
2. 按 Phase 2a 列出“原问题/派生来源 → 完整归档标题 → 分类 → 新增/合并/跳过/排除及原因”，并展示实际问答补丁预览。
3. 完整已有则跳过；缺少要点则在对应问答中增量补充；新问题归入相关分类。结论冲突时保留正确依据，无法确定则标记待核实，不将矛盾答案并列当作定论。
4. 保持既有标题层级、分类、编号及简答风格，不批量改写旧答案、重排文档或添加每题时间戳；仅在用户明确要求时重构。新建文档采用“文档标题 → 领域分类 → 完整问题 → 精炼答案”结构。
5. 预览后按已获授权直接写入；核对所有问题均有处理结果、答案覆盖要点、引用可独立理解且无重复。只在选定自学文档归档同一问题，除非用户明确要求多份维护。
6. 写入后报告新增、补充、跳过条目及绝对路径；继续执行 Phase 5 的仓库检测与 Git 授权规则。全部已覆盖则报告无需修改，不产生空提交。

需要选择目标或 Git 操作时，沿用主技能的 AskQuestion 降级规则；工具不可用须说明并改用纯文本确认，用户回复前不执行依赖该选择的操作。
