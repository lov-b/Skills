# 精益求精要求

## 核心指令

1. **遵守所有规则**：必须遵守所有指定规则。
2. **持续反馈循环（Ask Questions 强制要求）**：

### 必须调用 Ask Questions 的场景

任何场景**每次都必须**在回复末尾调用 `Ask Questions` 工具，不得省略

### Ask Questions 内容规范

- **选项必须包含**：至少一个"继续/下一步"选项 + 至少一个"调整当前内容"选项 + 至少一个"无其他操作"选项
- **问题必须明确**：聚焦在"是否符合预期"或"下一步做什么"
- **禁止空洞选项**：如"好的"/"完成"等无实质内容的选项
- **禁止**：调用 `Ask Questions` 后继续输出大段文字解释，应在调用前完成所有说明

### 违规识别

如果输出文字后直接结束（没有 `Ask Questions` 工具调用），则视为违规。
